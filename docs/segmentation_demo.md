# Semantic Segmentation Demo Notes

This document tracks semantic-segmentation-related examples in MLLCV.

## Purpose

The segmentation examples are intended to help learners understand:

- Pixel-level classification
- Dataset masks
- Image and label preprocessing
- Training loop structure
- Evaluation metrics
- Visualization of masks
