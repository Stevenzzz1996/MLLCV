# YOLO Demo Notes

This document tracks YOLO-related examples in MLLCV.

## Purpose

The YOLO examples are intended to help learners understand:

- Object detection workflow
- Input preprocessing
- Anchor boxes
- Bounding box decoding
- Non-maximum suppression
- Training and inference structure
- Keras-based implementation details

## Current Status

Some YOLO examples may be legacy code and may require specific TensorFlow/Keras versions.

Before running, check:

- Python version
- TensorFlow version
- Keras version
- Dataset path
- Model weight path
- Input image path

## Safety Notes

Do not commit large model weight files to the repository.

Use external storage or release assets for large files if needed.
