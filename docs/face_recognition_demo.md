# Face Recognition Demo Notes

This document tracks face-recognition-related examples in MLLCV.

## Purpose

The face recognition examples are intended for learning:

- Face image preprocessing
- Feature extraction
- Similarity comparison
- Basic recognition pipeline
- OpenCV-based image processing

## Privacy Notes

Face recognition can involve sensitive personal data.

Please do not commit:

- Real private face datasets
- Personal photos without permission
- Biometric data
- Private identity labels

Use public datasets or synthetic/demo images when possible.
