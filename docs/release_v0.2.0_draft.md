# MLLCV v0.2.0 - VLA Data Recording Roadmap

This release extends MLLCV from a low-latency tracking prototype into a data-recording and VLA-training preparation project for robotic gimbal perception.

## Highlights

- Added VLA episode schema
- Added JSONL observation-action writer
- Added mock VLA recording demo
- Added dataset validation stub
- Added LeRobot integration plan
- Added VLA roadmap documentation
- Added safety and privacy documentation

## Current Scope

This version does not claim to provide a complete VLA model. The current goal is to stabilize the data recording format and prepare the project for future imitation-learning and LeRobot-compatible policy training.

## Safety

Real videos, private scenes, credentials, and private model weights should not be committed to this repository.
