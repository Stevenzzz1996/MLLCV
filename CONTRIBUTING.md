# Contributing to MLLCV

Thank you for your interest in contributing to MLLCV.

MLLCV is an educational computer vision repository. Contributions should focus on making the project easier to understand, run, reproduce, and maintain.

## Ways to Contribute

You can help by:

- Improving documentation
- Fixing broken examples
- Adding reproducible tutorials
- Adding small demo scripts
- Reviewing dependencies
- Reporting bugs
- Adding repository health checks
- Improving security and code quality

## Before Opening a Pull Request

Please make sure that:

- Your change is related to computer vision learning, examples, documentation, or maintenance
- You do not include private datasets, credentials, API keys, or tokens
- You do not upload large model files such as `.pth`, `.pt`, `.onnx`, `.engine`, `.h5`, `.weights`
- Your documentation is clear enough for beginners
- Your code does not require unnecessary heavy dependencies

## Pull Request Guidelines

A good PR should include:

- A clear title
- A short explanation of what changed
- Steps to test or verify the change
- Screenshots or logs if relevant
- Notes about dependencies if needed

## Issue Guidelines

When opening an issue, please include:

- What you tried to do
- What you expected to happen
- What actually happened
- Your operating system and Python version
- Relevant error logs
- The submodule or script involved

## Code Style

This repository contains legacy examples, so strict formatting is not enforced yet. New code should be simple, readable, and well-commented.
