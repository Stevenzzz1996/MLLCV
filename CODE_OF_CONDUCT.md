# Code of Conduct

MLLCV is an open-source project for low-latency computer vision tracking and robotics perception. We want discussions to be useful for students, researchers, robotics developers, and real-time computer vision engineers.

## Expected Behavior

- Be respectful and constructive.
- Keep discussions focused on the project.
- Provide clear reproduction details when reporting problems.
- Treat hardware safety and security concerns seriously.
- Redact private RTSP URLs, credentials, recordings, and model paths.

## Unacceptable Behavior

- Harassment or personal attacks.
- Publishing private credentials, stream URLs, recordings, or sensitive data.
- Encouraging unsafe hardware operation.
- Intentionally misleading users about project stability, adoption, or performance.

Maintainers may close, edit, or lock discussions that are unsafe, abusive, or unrelated to the project.
