# Code of Conduct

MLLCV is an educational open-source project. We want this repository to be welcoming to students, beginners, researchers, and engineers.

Please be respectful when opening issues, reviewing pull requests, and discussing technical topics.

## Expected Behavior

- Be respectful and constructive
- Help beginners when possible
- Keep discussions focused on the project
- Provide clear technical details when reporting problems

## Unacceptable Behavior

- Harassment or personal attacks
- Posting private information
- Uploading credentials, secrets, or private datasets
- Intentionally misleading project users

If a discussion becomes unproductive, the maintainer may close or lock the issue.
